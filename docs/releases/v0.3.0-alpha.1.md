# Nébula 360 — v0.3.0-alpha.1 (pré-lançamento)

> ⚠️ **Esta versão NÃO roda no Xbox 360.** Ainda não existe executável para o
> console (`default.xex`): falta o compilador do Xbox 360. Esta pré-release é
> a **versão para PC (Linux)**, para testar a interface, a biblioteca e as
> ferramentas. Nada foi testado em um console real.

## O que tem nesta versão

- Interface 1280×720 navegável por controle (um controle de Xbox 360 ligado
  ao PC funciona) ou teclado: grade de jogos, abas por categoria, pesquisa
  com teclado virtual, favoritos, ordenação, detalhes do jogo e menus.
- Detecção de jogos: pastas com `default.xex`/`default.xbe` e contêineres
  GOD/XBLA (lendo só os cabeçalhos).
- Temas: Nébula Escuro, Nébula Claro e Alto Contraste.
- Registro de módulos com modo seguro após encerramentos inesperados
  (Menu › Módulos).
- Base da loja e dos downloads (verificação SHA-256, retomada, espaço livre).
  Ainda sem conexão com servidor.
- `nebula_scan`: ferramenta de linha de comando que roda o detector de jogos
  sobre pastas do PC, por exemplo uma cópia dos cabeçalhos dos jogos do seu
  console.

## Requisitos

- Linux x86-64 com glibc 2.38 ou mais nova (Ubuntu 24.04, Debian 13,
  Fedora 39 ou equivalentes).
- SDL2 instalado (ex.: `sudo apt install libsdl2-2.0-0`).

## Como usar

```bash
tar -xzf nebula360-0.3.0-alpha.1-linux-x86_64.tar.gz
cd nebula360-0.3.0-alpha.1-linux-x86_64
python3 tools/make_demo_data.py /tmp/demo     # biblioteca fictícia de demonstração
./nebula360 --data /tmp/demo/dados
```

Teclado: setas, Enter (A), Esc (B), X, Y, Q/E (LB/RB), PageUp/PageDown
(LT/RT), Tab (Back), M (Start), F12 (captura de tela), F10 (sair).

Para testar a detecção com os seus jogos reais, copie do console para o PC só
os arquivos pequenos (o `default.xex` de cada jogo extraído e o arquivo de
cabeçalho de cada GOD/XBLA, **sem** a pasta `.data`), mantendo as pastas, e
rode:

```bash
./nebula_scan --json /caminho/da/copia
```

## Verificações desta build

Feitas automaticamente pelo GitHub Actions antes da publicação:

- 75 testes automatizados em Linux x86-64;
- os mesmos testes em PowerPC 32-bit big-endian (qemu), a mesma ordem de
  bytes do Xbox 360.

## Limitações conhecidas

- Sem versão para Xbox 360; lançar jogos no PC só mostra um aviso.
- Leitura de GOD/XBLA validada só com dados sintéticos.
- Licença do projeto ainda não definida.
